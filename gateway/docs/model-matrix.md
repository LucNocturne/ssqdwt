# gpt-image-2 参数矩阵

> 基于 https://codemo.zeabur.app(CPA)+ ChatGPT Pro 实测,2026-04-25。

## 一句话总览

```
长边 ≤ 3840 px  ·  总像素 0.65–8.3 M  ·  长宽比可任意
透明底:不支持(OpenAI 上游硬限制)
```

## 一、size 矩阵 — 只看哪些能用

| 比例 | 1K(长边 1024) | 2K(长边 2048) | 4K(长边 3840) |
|:---:|:---:|:---:|:---:|
| 1:1 方图     | 1024×1024 | 2048×2048 | — |
| 4:3 / 3:4    | 1024×768 / 768×1024 | 2048×1536 / 1536×2048 | — |
| 5:4 / 4:5    | 1024×819 / 819×1024 | 2048×1638 / 1638×2048 | — |
| 3:2 / 2:3    | (临界,推荐升 2K) | 2048×1365 / 1365×2048 | — |
| 16:9 / 9:16  | (像素过小,升 2K) | 2048×1152 / 1152×2048 | **3840×2160 / 2160×3840** ★ |
| 2:1 / 1:2    | (像素过小,升 2K) | 2048×1024 / 1024×2048 | 3840×1920 / 1920×3840 |
| 21:9 / 9:21  | (像素过小,升 2K) | 2048×878 / 878×2048 | 3840×1646 / 1646×3840 |

**规律**:**1K 适合方/近方比例**(1:1、4:3、5:4),**4K 仅适合宽屏比例**(16:9 起到 21:9),**2K 全适用**。

## 二、quality 矩阵

| 档位 | Plus | **Pro(本网关)** | 单图大小 | 用途 |
|:---:|:---:|:---:|:---:|:---|
| `low` | 通 | 通 | ~0.5 MB | 占位 / 草图 / 极速 |
| `medium` | 通 | 通 | ~1.3 MB | 日常 |
| `high` | 静默降级 | **真高清** | 1.5–6 MB | 海报 / 印刷 / 4K |
| `auto` | 同上 | 同上 | — | 让模型自己选 |

## 三、其他参数

| 参数 | 取值 | 备注 |
|:---|:---|:---|
| `output_format` | `png` / `webp` / `jpeg` | png 默认 / webp 体积小 / jpeg 大批量节流 |
| `background` | `auto` / `opaque` | transparent **不支持**,后处理抠图 |
| `n` | 1–8 | 网关上限 8,单号串行,n 越大越慢 |
| `moderation` | `auto` / `low` | 企业版才有意义 |
| `response_format` | `b64_json` | CPA 只走这条 |
| `prompt` 长度 | ≤ 32 KB | 网关层限 |

## 四、本网关暴露的全部 model

> 命名规则:`img-{1k|2k|4k}-{宽}x{高}`,默认 high 画质。`img-standard` 与 `img-1k-1024x1024-low` 为两个特殊别名(画质档位区分)。

### 1K 档(长边 1024)

| 命名 | size | quality | credits | 用途 |
|:---|:---|:---:|:---:|:---|
| `img-standard` ⭐ | 1024×1024 | medium | **1** | 兼容入门,缩略图/占位图 |
| `img-1k-1024x1024-low` | 1024×1024 | low | **1** | 极速档(~10s),大批量草图 |
| `img-1k-1024x1024` | 1024×1024 | high | **3** | 1K 方图高清 |
| `img-1k-1024x768` / `img-1k-768x1024` | 1024×768 / 768×1024 | high | **1** | 4:3 / 3:4 横竖图 |

### 2K 档(长边 2048,全比例可用)

| 命名 | size | quality | credits | 用途 |
|:---|:---|:---:|:---:|:---|
| `img-2k-2048x2048` | 2048×2048 | high | **8** | 2K 方图 |
| `img-2k-2048x1536` / `img-2k-1536x2048` | 2048×1536 / 1536×2048 | high | **8** | 4:3 / 3:4 |
| `img-2k-2048x1638` / `img-2k-1638x2048` | 2048×1638 / 1638×2048 | high | **8** | 5:4 / 4:5,小红书 / Instagram |
| `img-2k-2048x1365` / `img-2k-1365x2048` | 2048×1365 / 1365×2048 | high | **8** | 3:2 / 2:3,单反产品摄影 |
| `img-2k-2048x1152` / `img-2k-1152x2048` | 2048×1152 / 1152×2048 | high | **3** | 16:9 / 9:16 |
| `img-2k-2048x1024` / `img-2k-1024x2048` | 2048×1024 / 1024×2048 | high | **3** | 2:1 / 1:2 banner |

### 4K 档(长边 3840,仅宽屏)

| 命名 | size | quality | credits | 用途 |
|:---|:---|:---:|:---:|:---|
| `img-4k-3840x2160` / `img-4k-2160x3840` ⭐ | 3840×2160 / 2160×3840 | high | **16** | 真 4K UHD |
| `img-4k-3840x1920` / `img-4k-1920x3840` | 3840×1920 / 1920×3840 | high | **16** | 真 4K 2:1 banner |
| `img-4k-3840x1646` / `img-4k-1646x3840` | 3840×1646 / 1646×3840 | high | **16** | 21:9 / 9:21 电影超宽屏 |
